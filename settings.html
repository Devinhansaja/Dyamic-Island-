While a game is full-screen

Notch shows
Network speedDownload and upload in the performance strip

The performance strip shows CPU, GPU load and temperature, VRAM and RAM, and stays click-through so it never gets in the way. GPU temperature and VRAM come from NVIDIA's driver; other GPUs show load only.

FPS isn't shown: Windows only gives frame timing to apps running as administrator.

Games in exclusive full-screen mode draw above every other window. Use borderless or windowed full-screen to see the strip.
